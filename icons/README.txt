Optional class icons
====================

Put one image per class in this folder, named after the class in lower case with no spaces:

    warrior.png   paladin.png   hunter.png   rogue.png   priest.png   shaman.png
    mage.png      warlock.png   monk.png     druid.png   demonhunter.png
    deathknight.png   evoker.png        (.jpg also works)

On startup the bot uploads each image once as its own emoji, and the raid posts and menus show them.
Without icons the bot uses coloured squares instead, which works fine.

This project does not ship any icons, because class artwork belongs to Blizzard Entertainment.
Only use images you have the right to use. Images placed here are git-ignored so they don't end up in the repository.
